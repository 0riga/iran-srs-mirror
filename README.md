# iran-srs-mirror

Зеркало выбранных `.srs` из [Chocolate4U/Iran-sing-box-rules](https://github.com/Chocolate4U/Iran-sing-box-rules) (ветка `rule-set`), публикуется релизами — чтобы их можно было подключить как источник в [splify2-lists](https://github.com/0riga/splify2-lists) через `sources.txt`.

Обновляется автоматически раз в сутки (`.github/workflows/mirror-srs.yml`), новый релиз появляется только если изменились именно эти файлы (тег собирается из их blob-sha в дереве ветки-источника).
